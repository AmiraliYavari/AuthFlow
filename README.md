# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/AmiraliYavari/AuthFlow.git
```

## Go To Project

```bash
cd AuthFlow
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```
